DUInterrupt

Written in Swift

This app extracts heart rate data and runs a reaction time test from the user's Apple Watch, which it then imports to the user's iPhone/iPad. The DUInterrupt App then uses this data to determine, to a moderate degree of certainty, if the user is intoxicated by alcohol and pings an ride service like Uber if required.
